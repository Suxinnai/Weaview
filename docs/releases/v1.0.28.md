# Weaview v1.0.28

This release fixes the first Skills installation flow and improves image/edit task continuity.

## Highlights

- Install GitHub Skills directly from the app by downloading `SKILL.md`; a local runner is no longer required for installation.
- Support GitHub root repos and `/tree/branch/subdir` Skill paths.
- Keep the runner only for confirmed local script execution.
- Replace edited user messages in place and regenerate from the original branch point.
- Reuse previous generated images for additive follow-up edits.
- Keep background-interrupted image generations resumable when the app returns to the foreground.
