# Weaview v1.0.31

This release refreshes the Android launcher icon and removes the unsupported mobile Skills surface.

## Highlights

- Replace the launcher artwork with the new transparent-background icon provided for this release.
- Regenerate Android launcher icon density assets for mdpi, hdpi, xhdpi, xxhdpi, and xxxhdpi.
- Remove Skills UI, GitHub Skill installation, Skill Runner configuration, automatic Skill matching, and Skill context injection from the mobile app.
- Keep the core chat, provider configuration, web search, image, file, TTS, backup, and local data management flows.
