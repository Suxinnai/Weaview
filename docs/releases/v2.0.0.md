# Weaview v2.0.0

织境 2.0 是一次面向多模型创作、移动端操作效率和稳定性的主版本升级。

Weaview 2.0 is a major release focused on multi-model creation, efficient mobile workflows, and runtime stability.

## 中文更新内容

### 主流生图模型全面接入

- Gemini 内置 Nano Banana 2 Lite、Nano Banana 2、Nano Banana Pro 与上一代 Nano Banana。
- 支持 OpenAI / GPT Image、Grok Imagine、Seedream 5/4、Recraft、Stability AI、FLUX.2/1.1、Ideogram，以及 Replicate 官方 Imagen、Qwen Image 等模型。
- 各提供商按兼容接口或原生协议路由，保留模型发现和连接测试能力。

### 一次生成多张图片

- 单次可选择输出 1–4 张图片。
- 支持 Gemini 同响应多图解析与缺失结果补发。
- 支持火山方舟和 FLUX.2 多参考图输入。
- 新增成组画廊、全屏翻页、多选和逐张保存体验。

### 更简洁的设置与交互

- 设置顶部精简为“通用 / 提供商 / 模型 / 更多”。
- 辅助模型自动复用主对话模型，减少重复配置。
- 提供商按常用项渐进展开，降低首次配置复杂度。
- 修复昵称与强调色不可编辑的问题，加入主题切换过渡并支持系统“减少动态效果”。
- 移除首次进入引导和首页冗余配置提示。

### 稳定性与安全性

- 优化启动状态恢复和解码图片缓存上限，降低长会话及多图场景中的异常内存占用。
- 加强备份导入的压缩包大小、条目数量、单条目大小和真实解压体积校验。
- 补充启动恢复、备份安全、设置交互、生图、多图画廊、模型角色和能力识别测试。

## English release notes

### Broad image-model support

- Added built-in Gemini presets for Nano Banana 2 Lite, Nano Banana 2, Nano Banana Pro, and the legacy Nano Banana model.
- Added OpenAI / GPT Image, Grok Imagine, Seedream 5/4, Recraft, Stability AI, FLUX.2/1.1, Ideogram, and official Replicate models such as Imagen and Qwen Image.
- Providers use their compatible or native protocols while retaining model discovery and connection testing.

### Multiple images per generation

- Generate 1–4 images in one task.
- Collect multiple final Gemini images and fill missing variants when needed.
- Use multiple reference images with Ark and FLUX.2.
- Browse results in a grouped gallery with fullscreen paging, multi-select, and per-image saving.

### Simpler settings and smoother interactions

- Reorganized settings into General, Providers, Models, and More.
- Auxiliary roles reuse the main chat model to reduce repetitive setup.
- Provider presets expand progressively, keeping initial configuration focused.
- Fixed editable nickname and accent controls, added smooth theme transitions, and respected the system reduced-motion setting.
- Removed first-run onboarding and redundant configuration prompts from the home screen.

### Stability and safety

- Improved startup restoration and bounded decoded-image caching to reduce abnormal memory growth in long chats and multi-image workflows.
- Hardened backup imports with archive-size, entry-count, per-entry, and real inflated-size limits.
- Expanded regression coverage for startup restore, backup safety, settings interactions, image generation, galleries, role assignment, and capability detection.
