# Weaview v1.1.0

This release repositions Weaview as a mobile Agent assistant and restores executable Skills through the remote Skill Runner path.

## Highlights

- Rework the first-run empty state, header, composer hints, sidebar labels, and product copy around task-oriented Agent assistance.
- Execute Runner Skills through the configured remote Skill Runner instead of silently treating every Skill as prompt context.
- Keep context-only `SKILL.md` imports available and label them separately from Runner-executed Skills.
- Add `SkillConfig.executionMode` so legacy context Skills and executable Runner Skills have explicit behavior.
- Replace the Flutter app icon and Android launcher density assets with the supplied production artwork.
- Update README, pubspec metadata, system prompt, and regression coverage.
