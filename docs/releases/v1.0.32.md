# Weaview v1.0.32

This release turns Weaview's chat flow into a more durable creative workspace with memory cards, multi-model comparison, branch visualization, reusable work cards, and local usage estimates.

## 中文亮点

- 结构化记忆卡片：支持来源、参与上下文开关、置顶和设置页管理。
- 多模型对照：将多个已配置聊天模型并列生成，方便比较风格、质量和成本。
- 分支图谱：展示会话从关键消息分叉出的路径，并支持直接切换节点。
- 编织板 / 作品卡：可把高价值回复保存为可复用作品片段，支持置顶和删除。
- Token 用量统计：本地估算输入/输出 token、调用来源、模型汇总和美元花费。
- UI 打磨：优化工作台面板摘要、空态、卡片密度，并将高级工具收纳进输入框加号菜单。

## English Highlights

- Structured memory cards with source metadata, context toggles, pinning, and settings management.
- Multi-model comparison for side-by-side responses from configured chat models.
- Branch graph for visualizing conversation forks and switching directly between nodes.
- Weaving board and work cards for saving reusable creative snippets from useful replies.
- Token usage statistics with local estimates for input/output tokens, source categories, model summaries, and USD cost.
- UI polish for workspace panels, empty states, card density, and the composer tool menu.
