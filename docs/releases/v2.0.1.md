# Weaview v2.0.1 / 织境 v2.0.1

## 中文

此版本重点修复首页和对话体验，并补齐自定义 Gemini 兼容网关的文本与生图支持。

- 首页恢复原有的菜单、模型选择、中央品牌标题和底部单层输入框排版。
- 对话消息重新调整头像、气泡、正文行距和留白；点击消息后以紧凑半透明胶囊展示操作按钮，不再出现整行省略号空白条。
- 错误消息改为简洁卡片，提供切换模型、重试和折叠的技术详情。
- Gemini 官方接口使用原生 Interactions 生图；自定义 OpenAI 兼容地址使用 `/chat/completions` 并解析 `message.images`。
- 支持自定义 Gemini 文本模型、手动模型 ID、兼容模型列表，以及一次生成 1–4 张图片。
- 恢复设置中的直接分类、助手头像和情绪回应控制，并优化主题、强调色、昵称、启动速度与后台内存占用。

Android 用户通常应下载 `arm64-v8a` 版本；较老的 32 位设备使用 `armeabi-v7a`，模拟器或少数 x86_64 设备使用 `x86_64`。

## English

This release focuses on restoring the home and conversation experience while completing text and image support for custom Gemini-compatible gateways.

- Restored the established home layout with its menu, model selector, centered brand statement, and single-layer bottom composer.
- Refined conversation avatars, bubbles, typography, spacing, and message actions. Tapping a message now opens one compact translucent action capsule instead of a full-width ellipsis strip.
- Replaced raw request payloads with concise error cards offering model switching, retry, and collapsible technical details.
- Official Gemini image generation uses the native Interactions API; custom OpenAI-compatible endpoints use `/chat/completions` and parse `message.images`.
- Added reliable custom Gemini text routing, manual model-ID handling, compatible model discovery, and 1–4 image outputs.
- Restored direct settings categories, assistant avatar and emotional-response controls, while improving themes, accent editing, nicknames, startup latency, and background memory use.

Most Android phones should download the `arm64-v8a` build. Use `armeabi-v7a` for older 32-bit devices and `x86_64` for compatible emulators or devices.
