# Weaview v2.0.2 / 织境 v2.0.2

## 中文

v2.0.2 是一次围绕「更清楚、更安静、更可靠」的体验更新。模型与提供商仍然保持开放配置，但日常操作不再需要穿过一层层按钮和重复信息。

### 界面与交互

- 聊天模型选择器升级为真正的玻璃态浮层：高斯模糊、半透明渐变、统一用途筛选、即时搜索、能力标签与明确的当前模型状态。
- 提供商改为从左到右、从上到下排列的两列小卡片；长按后可以拖拽排序或删除，当前提供商以选中状态直接表达。
- 主题切换改为更协调的视觉卡片，强调色保持一触即选；关于页合并重复的版本和仓库信息。
- 设置页保留清晰的六个分类，并统一页头、分组、卡片、动效和可触控尺寸。
- 会话分支直接嵌套在主会话下方，根会话与子分支都可以独立折叠。

### 模型与生图

- 默认模型新增独立的翻译模型和标题生成模型配置，不再强制复用主对话模型。
- 模型分配继续校验提供商启用状态与能力，禁用提供商时会清理失效分配。
- 修复生成一张图片时结果不显示的问题。
- 多图结果改为 PhotoStack 风格卡组，减少对话中的纵向占用，同时保留数量标记、全屏翻页和逐张保存。
- 生图追问保持文本上下文，并在需要修改上一张图片时继续携带正确的参考图。

### 安全、备份与发布质量

- Android API Key 使用 Keystore 支持的加密存储，并自动清理普通偏好设置中的旧明文字段。
- 远程 Provider、搜索和 TTS 地址必须使用 HTTPS；`localhost`、`127.0.0.1` 与 `::1` 仍允许 HTTP 调试。
- ZIP 备份支持携带有效附件并恢复到应用私有目录，同时限制条目数量、解压体积、附件大小和危险路径。
- 备份不会导出可直接使用的 API Key。
- CI 强制执行静态检查、218 项测试、覆盖率门槛和 Android 构建；正式 APK 必须使用独立发布签名。

### 维护者吐槽

把一个设置页做得「看起来没有那么多设置」，最终牵动了提供商排序、六类默认模型、分支树、备份格式和半个测试套件。好消息是，它现在终于不像机场自助终端了。

### 下载

绝大多数 Android 手机请选择 `arm64-v8a`。较老的 32 位设备使用 `armeabi-v7a`；模拟器或少数兼容设备使用 `x86_64`。

> 兼容性提醒：本版本要求 Android 7.0 或更高版本。远程明文 HTTP API 地址将不再工作，请改用 HTTPS。

## English

v2.0.2 is focused on making Weaview clearer, quieter, and more dependable. Providers and models remain fully configurable, but everyday actions no longer sit behind layers of repeated controls and information.

### Interface and interaction

- Upgraded the in-chat model picker to a true glass surface with Gaussian blur, translucent gradients, unified purpose filters, instant search, capability chips, and an unmistakable current-model state.
- Reorganized providers into compact two-column cards ordered left-to-right and top-to-bottom. Long press to drag, reorder, or delete; the current provider is communicated directly through selection styling.
- Replaced the awkward theme control with coordinated visual cards and kept accent colors one tap away; consolidated repeated version and repository details on About.
- Preserved six clear settings categories while standardizing headers, groups, cards, motion, and touch targets.
- Nested branch conversations directly beneath their parent session, with independent collapsing for roots and child branches.

### Models and image generation

- Added independent default assignments for translation and title generation instead of forcing both tasks through the primary chat model.
- Continued to validate provider availability and model capabilities, clearing stale assignments when a provider is disabled.
- Fixed the missing result when generating a single image.
- Replaced tall multi-image output with a PhotoStack-style stack, retaining count indicators, fullscreen paging, and per-image saving.
- Kept image follow-ups text-aware while carrying the correct reference image only when the user asks to edit a previous result.

### Security, backups, and release quality

- Moved Android API keys to Keystore-backed encrypted storage and removed legacy plaintext preference fields after migration.
- Remote provider, search, and TTS endpoints now require HTTPS; `localhost`, `127.0.0.1`, and `::1` remain available for local HTTP development.
- ZIP backups now include valid attachments and restore them into private app storage while enforcing entry-count, inflated-size, attachment-size, and path-safety limits.
- Backups never export usable API keys.
- CI now enforces static analysis, all 218 tests, a coverage floor, and an Android build. Release APKs require dedicated production signing.

### Maintainer's grumble

Making a settings screen look like it has fewer settings somehow touched provider ordering, six model roles, the branch tree, backup format, and half the test suite. The good news: it finally stopped looking like an airport check-in kiosk.

### Downloads

Most Android phones should use `arm64-v8a`. Choose `armeabi-v7a` for older 32-bit devices and `x86_64` for compatible emulators or uncommon devices.

> Compatibility note: Android 7.0 or newer is required. Remote cleartext HTTP API endpoints no longer work; migrate them to HTTPS.
