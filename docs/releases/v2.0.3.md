# Weaview v2.0.3 / 织境 v2.0.3

## 中文

v2.0.3 是一次针对真实手机使用反馈的交互修复。重点不是再堆一层视觉效果，而是让拖拽、配置和输入这些高频动作符合用户直觉。

### 提供商与模型管理

- 提供商与模型卡片从原位置跟手拖动，不再从右上角出现错位副本。
- 拖拽期间隐藏原位置的视觉副本，只保留一个清晰的活动卡片。
- 长按后的删除入口改为克制的红色小 ×，替代抢眼的大号垃圾桶按钮。
- 所有已配置且启用的提供商显示强调色边框；当前提供商使用更强边框，不再填充整张卡片。
- 提供商模型列表采用相同的拖拽、排序和删除交互。

### 配置与兼容性

- 提供商和语音服务的 API Key 输入框增加显示/隐藏按钮。
- Base URL 同时支持 HTTP 与 HTTPS。
- 使用 HTTP 时显示明文传输警告，提醒 API Key 和对话内容可能被中间人读取；建议仅在可信网络或内网服务中使用。
- 语音服务类型从旧式系统下拉菜单改为 MiMo、OpenAI、自定义三张紧凑选择卡。

### 输入与默认模型

- 输入框功能菜单压缩为相册、文件、联网和多模型对比四个等宽方形入口，大幅减少展开后的纵向占用。
- 工具菜单与正文输入区之间加入虚线分隔，信息层级更清晰。
- 修复长模型名称挤压“主对话模型”等角色标题并撑高卡片的问题；所有默认模型行都使用有界、单行省略布局。

### 质量验证

- Flutter 静态分析无问题。
- 完整 222 项自动化测试全部通过。
- 已在 Android API 35 模拟器上验证拖拽反馈、删除入口、HTTP 提示、默认模型布局、输入菜单和语音服务配置。
- 正式 APK 继续通过 GitHub Actions 使用独立发布签名构建。

### 维护者吐槽

“把卡片从右上角召唤出来”听起来像个魔法特效，放在拖拽排序里却只像程序在闹鬼。现在它终于肯老老实实待在手指下面了。

### 下载

绝大多数 Android 手机请选择 `arm64-v8a`。较老的 32 位设备使用 `armeabi-v7a`；模拟器或少数兼容设备使用 `x86_64`。

> 兼容性提醒：本版本要求 Android 7.0 或更高版本。HTTP Base URL 可以使用，但连接内容不会被传输层加密。

## English

v2.0.3 is an interaction-focused patch based on real-device feedback. Instead of adding another decorative layer, this release makes dragging, configuration, and composing behave the way people naturally expect.

### Provider and model management

- Provider and model cards now begin dragging from their actual position instead of spawning an offset duplicate near the upper-right corner.
- The source placeholder is visually hidden while dragging, leaving one clear active card.
- Replaced the oversized trash control with a restrained red × shown after a long press.
- Every configured and enabled provider receives an accent outline. The current provider uses a stronger border without filling the entire card.
- Provider model lists now use the same drag, reorder, and delete interaction.

### Configuration and compatibility

- Added show/hide controls to API-key fields for providers and speech services.
- Base URLs now support both HTTP and HTTPS.
- HTTP endpoints display a cleartext warning because API keys and conversation content may be readable in transit. Use them only on trusted networks or internal services.
- Replaced the legacy platform dropdown for speech-service types with compact MiMo, OpenAI, and Custom selection cards.

### Composer and default models

- Condensed the composer utility menu into four equal square actions for Photos, Files, Web, and Model Comparison, substantially reducing its expanded height.
- Added a dashed divider between the utility menu and the text composer.
- Fixed long model names squeezing role labels such as Primary Chat Model and stretching the card. Every assignment row now uses bounded single-line truncation.

### Quality verification

- Flutter static analysis passes with no issues.
- All 222 automated tests pass.
- Verified drag feedback, delete controls, HTTP warnings, default-model layout, composer tools, and speech configuration on an Android API 35 emulator.
- Release APKs continue to be built with dedicated production signing through GitHub Actions.

### Maintainer's grumble

“Summon the card from the upper-right corner” sounds like a magical effect. In drag sorting, it mostly looked like the app was haunted. The card now behaves and stays under your finger.

### Downloads

Most Android phones should use `arm64-v8a`. Choose `armeabi-v7a` for older 32-bit devices and `x86_64` for compatible emulators or uncommon devices.

> Compatibility note: Android 7.0 or newer is required. HTTP Base URLs are supported, but their traffic is not encrypted at the transport layer.
