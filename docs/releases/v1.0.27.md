# Weaview v1.0.27

![Weaview v1.0.27 cover](v1.0.27-cover.png)

This release adds the first local Skills system for Weaview.

## Highlights

- Install compatible Skills from GitHub URLs.
- Manage Skills in settings: enable, disable, delete, edit triggers, and edit prompts.
- Pin a Skill from the chat input dock, or let Weaview recommend one locally from triggers and URLs.
- Confirm every external Skill run before the local runner receives the input.
- Use the bundled Python `tool/skill_runner` for local development and personal use.
- Route `gpt-image-2` image requests through Responses first; keep other image models on `/v1/images/generations` first.
- Keep background/theme changes closer to Weaview's low-saturation, literary style.
