# Weaview v1.0.30

This release improves the settings experience, local data portability, provider control, and Skill usage flow.

## Highlights

- Polish settings main-menu, secondary-page, back navigation, and tab transitions with reduced-motion support.
- Derive the About screen version from `pubspec.yaml` instead of hard-coded constants.
- Add merged backup import for `weaview-export.json` and zip archives containing it.
- Preserve local secrets when imported backups contain masked `***` API keys.
- Add provider disable state so disabled providers are excluded from model selection, defaults, and fallback.
- Move Skills into a dedicated settings subpage with trigger, pinned, enabled, and SKILL.md context editing.
- Auto-match Skills in chat by injecting Skill context directly, without confirmation dialogs or runner execution.
- Remove voice input, microphone UI, Android speech channel, and recording permission while keeping TTS.
- Refresh the launcher icon with an optimized original-style Weaview illustration and regenerated Android density assets.
