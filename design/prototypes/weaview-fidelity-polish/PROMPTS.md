# 原型生成提示词集

全部原型使用 OpenAI 内置 `imagegen` 生成，并以当前应用截图与选定主页方案作为视觉参考。

## 共用基础提示

> 为“织境 Weaview”生成高保真竖屏移动端 UI 原型。它首先是多模态 AI 对话助手，图片生成、联网搜索、附件和多模型对比属于对话能力。延续雾白、极淡青蓝与鼠尾草绿柔光、深蓝灰中文排版和克制青绿色强调；使用 18–22px 圆角、1px 冷灰边框、极少阴影和不小于 44px 的触控目标。仅展示应用内容，不展示设备外壳、系统状态栏、欢迎引导、促销模块或与当前产品无关的功能。输出应像可直接交付 Flutter 工程师实现的完整页面。

## 页面补充提示

1. 主页：统一菜单、模型选择器和新建对话的尺寸，删除首屏引导与配置卡。
2. 模型下拉：紧凑浮层、搜索、对话/图像筛选、提供商分组、选中状态与模型管理入口。
3. 侧边栏：新建对话、三个工作区入口、分组历史和固定账户区。
4. 正常对话：多模态用户消息、结构化回答、思考折叠、消息操作与固定输入器。
5. 工具面板：附件、相机、联网搜索、图片生成、多模型对比和文件分析。
6. 生图配置：Gemini 图片模型、画幅、1–4 张输出、多参考图与对话式提示输入。
7. 生图结果：2×2 图片网格、选择、保存、分享、编辑和重新生成。
8. 单图查看：沉浸式查看、缩略图胶片、局部重绘、扩展画布和作为参考图。
9. 对比选择器：最多三个模型、搜索、提供商筛选、选中汇总。
10. 对比结果：顶部模型切换、单列回答、采用回答、对比摘要和同步追问。
11. 分支图谱：树状节点、当前路径、节点详情与从此处创建分支。
12. 工作台：移动端单列状态看板、对话待办识别和任务详情。
13. 用量统计：请求、Token、图片、每日用量和提供商分布。
14. 通用设置：外观、个人资料、人设、情绪化回应、记忆与语言。
15. 提供商：连续列表、连接状态、模型数量、启用开关和导入配置。
16. Gemini 详情：凭证、连接测试、同步模型和四个图片模型 API ID。
17. 默认模型：主对话、总结、建议、翻译、工具和生图六种角色。
18. 扩展服务：搜索、网页读取、来源引用、语音和实验能力。
19. 数据管理：存储、备份、迁移、保留策略和不可撤销操作。
20. 关于织境：版本、更新、帮助、法律、诊断、仓库和许可。
21. 系统提示词：文本编辑、变量、预览、作用范围和保存状态。
22. 人物画像：基本信息、回答偏好、关注方向、当前项目和使用方式。
23. 记忆管理：搜索、分类、编辑、停用、删除、归档与清空。
24. 搜索服务：凭证、搜索偏好、连接测试与结果预览。
25. 语音服务：来源、音色试听、参数、自动朗读和测试文本。
26. 问题反馈：类型、描述、附件、诊断信息、联系方式和敏感信息提醒。
