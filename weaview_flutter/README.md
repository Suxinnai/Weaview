# 织境 Flutter App

这是织境的 Flutter 移动端主工程。完整项目介绍、安装方式、贡献流程和开源许可请阅读仓库根目录的 [README.md](../README.md)。

## 快速运行

```bash
flutter pub get
flutter run
```

## 常用检查

```bash
flutter analyze

```
